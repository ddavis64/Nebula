# Nebula
Creating a Nebula Overlay Network for a home LAN using a Raspberry Pi 5 to provide a private, secure, encrypted network for communication devices.
# Objectives Statement:
The goal of this project is to create and deploy a Nebula Overlay Network with a Raspeberry Pi 5 as the lighthouse and Pi-hole as an ad blocker. My home network will be used as a Nebula node with at least one personal device connected for the overlay. The final outcome will include my phone as the Nebula host demonstrating remote connectivitiy to the home network while not connected to the local network and ads being blocked.
# Tasks
1) Install and configure Nebula on a Raspberry Pi to act as the lighthouse.
Add your home LAN as a Nebula node (gateway into your home subnet).
Register at least one peripheral device on this overlay.
Configure a mobile phone with the Nebula client and proper certificates.
Test connectivity: from the phone, access the peripheral device via Nebula while disconnected from Wi-Fi (e.g., on LTE/5G).
Document and publish Nebula network configs for lighthouse, home node, and phone host.
# Materials Needed
Nebula Open Source Software configs
Raspberry Pi 5 (light house)
Home Node (LAN gateway)
iPhone 17 (host)
